    Open a project

    A project is a folder with a feeding.yaml: it says where the videos and SLEAP model(s) are, and holds the bowl annotations, predictions and results. Open an existing one or create a new one.

        Project settings

        Videos ?

        Drop video files here, or — they are copied into the project's videos/ folder.
        Folders used in place:

          SLEAP models ?

          Model folders from the library (), the project's models/ folder, or anywhere. Context blank = every video; give contexts (e.g. A, B) to use different models per context. Existing predictions keep the model they were made with.

          SLEAP inference ?

          Options for sleap-track. They apply to SLEAP runs started after saving; existing predictions keep the parameters they were made with (shown on each video).

          Tracking options (when a tracker is used)

          Naming ?

          How a video's file name maps to animal, condition and context. Named groups: animal (required), condition, context, session, part.

          Animals and groups ?

          Group labels (e.g. Control / Treated) used by the statistics. Saved to metadata/subjects.csv.
